Abrir `index.html` no navegador para rever antes de publicar. A Maquete Viva original é acedida por um link externo: o seu código-fonte não foi importado nem alterado. O espaço de vídeo é apenas um marcador. Confirmar o email de contacto no `index.html` antes de publicar.

## GitHub Pages (apenas após aprovação)
No repositório público `presera-site`, carregar os três ficheiros na raiz; depois Settings → Pages → Deploy from a branch → main → / (root) → Save. Aguardar a disponibilização do endereço apresentado pelo GitHub. Não é necessário serviço pago para o alojamento básico.
